Bem-vindo ao repositório oficial do projeto desenvolvido para o **Hackathon TV Box E10**. O objetivo principal desta iniciativa é a descaracterização de dispositivos de TV Box apreendidos, transformando hardware obsoleto ou irregular em ferramentas úteis e seguras para a sociedade (como minicomputadores educativos ou servidores locais).

> [!IMPORTANT]
> **Nota de Segurança:** Os procedimentos contidos na pasta `Descaracterização` devem ser executados com atenção ao modelo exato do processador e pinagem da placa para evitar o bloqueio permanente (*brick*) do hardware.

## 🎯 Sobre o Projeto
Este ecossistema foi desenhado durante a maratona do Hackathon com o intuito de:
1. **Remover o sistema operativo original** e quaisquer vestígios de software de streaming ilegal.
2. **Instalar uma ROM limpa** ou distribuição Linux customizada (ex: Armbian, Debian Light).
3. **Disponibilizar aplicações úteis** direcionadas à educação ou automação residencial básica.
